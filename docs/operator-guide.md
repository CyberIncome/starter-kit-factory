# Operator guide

## Create a customer kit

1. Open **Starter Kit Factory** from the Start Menu.
2. Select **New kit**.
3. Paste the customer details from the Etsy order.
4. Choose the customer’s approved visual theme and logo layout.
5. Confirm every service and price.
6. Check the live preview, then select **Generate kit**.
7. Select **Open folder** after generation.
8. Review the files, then send the ZIP through the Etsy made-to-order order workflow.

## If a customer needs a correction

Create a new kit using the corrected order details. The factory will replace the matching working folder and ZIP with the latest version.

## Important checks before delivery

- Business name is spelled correctly.
- Phone, email, service area, and booking link are correct.
- Services and prices exactly match the approved customer details.
- Flyer offer is correct.
- The service agreement has approved, jurisdiction-appropriate content.
- The customer receives the ZIP file, not the app installer.

## Backup

Back up `Documents/Starter Kit Factory` to a cloud drive or external drive on a regular schedule. This preserves the generated kits and local order history.
